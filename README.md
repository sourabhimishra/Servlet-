Java Servlet Form Handling Project

This project contains multiple Java Servlet programs demonstrating the use of both GET and POST HTTP methods. It covers fundamental concepts of web development using the Jakarta Servlet API and Apache Tomcat server.

The project includes examples such as login validation, student and employee registration forms, calculators (addition, multiplication, simple interest, area of rectangle), temperature conversion, dropdown and checkbox handling, hidden fields, form validation, redirection using sendRedirect(), and detecting the HTTP request method.

Each program shows how form data is sent from the browser and processed on the server using doGet() and doPost() methods. It demonstrates retrieving parameters using getParameter() and getParameterValues(), performing calculations, validating input fields, and generating dynamic HTML responses using PrintWriter.

The project follows a structured package format (com.example) and is compatible with Tomcat 10+ (Jakarta Servlet API). It is designed for beginners to understand servlet lifecycle, request-response handling, and client-server communication in Java web applications.

This repository is useful for academic practice, lab work, viva preparation, and building a strong foundation in Java web development.
